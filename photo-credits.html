Background segmentation runs locally using BiRefNet Lite ONNX (MIT), by Peng Zheng and the BiRefNet contributors, converted by the ONNX Community. The model revision is de15b22ba131738a16dff04aab8bdf8dc32e3ac1.

Browser inference uses Transformers.js 3.8.1 (Apache-2.0) and ONNX Runtime (MIT). Models and runtime assets are downloaded from Hugging Face and jsDelivr. Photo pixels are processed on this device; there is no paid inference API.
