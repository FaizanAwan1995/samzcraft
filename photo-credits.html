Local background removal uses U²-Net-P, by Xuebin Qin and contributors (Apache-2.0), and the ONNX conversion distributed by rembg (MIT).

The 4.6 MB model is the u2netp.onnx asset from rembg’s v0.0.0 Models release. It is downloaded from a pinned Hugging Face mirror and checked against the original release’s SHA-256: 309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8.

Inference uses ONNX Runtime Web 1.22.0 (MIT), downloaded from jsDelivr. Models/runtime files are cached when the browser allows it. Product pixels remain on this device; there is no paid inference API.
